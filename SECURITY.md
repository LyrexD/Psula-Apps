# Güvenlik politikası

## Desteklenen sürüm

Aktif olarak `main` branch'i ve son GitHub Release desteklenir.

## Güvenlik açığı bildirme

Güvenlik sorunlarını herkese açık issue yerine GitHub profilindeki iletişim adresinden özel olarak bildirin. Etkilenen sürümü, tekrar üretme adımlarını, olası etkiyi ve varsa önerilen düzeltmeyi ekleyin.

API anahtarı, imzalama anahtarı, keystore veya gerçek kullanıcı verisini issue, pull request ya da ekran görüntülerinde paylaşmayın.
