# Katkı rehberi

Psula'ya katkıda bulunduğunuz için teşekkürler.

1. Repoyu fork edin ve değişikliğiniz için odaklı bir branch açın.
2. Projeyi Android Studio ile açıp Gradle senkronizasyonunu tamamlayın.
3. Davranış değişiklikleri için test ekleyin veya mevcut testi güncelleyin.
4. `gradle testDebugUnitTest lintDebug assembleDebug` kontrollerini çalıştırın.
5. Pull request açıklamasında problemi, çözümü ve doğrulama yöntemini belirtin.

Büyük mimari veya ürün değişiklikleri için uygulamaya başlamadan önce issue açın. Güvenlik açıklarını herkese açık issue olarak paylaşmayın.
